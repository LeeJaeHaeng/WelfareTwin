# 10. 데모 · 발표 시나리오 (본선 12/3, 발표 5분 + 질의 5분)

## 1. 5분 발표 흐름
| 시간 | 내용 | 화면 |
|---|---|---|
| 0:00–0:40 | 문제: 사각지대는 사건 뒤에 발견된다. 협의 연 1,610건, 사전 검증 도구 없음 | 슬라이드 |
| 0:40–1:10 | 해법 한 줄: "정책을 사람에게 실험하기 전에 가상 대한민국에서 먼저" + 4레이어 구조도 | 슬라이드 |
| 1:10–1:50 | 데모① 법전 → 코드: 대구 지자체 사업 원문이 규칙이 되고 교차검증 통과 | 화면 1 |
| 1:50–2:40 | 데모② 사각지대 버튼 → 반례 가구 카드 + 탈락 조항 | 화면 2 |
| 2:40–3:20 | 데모③ 절벽 그래프: 소득 +10만원에 가처분소득 급감 구간 | 화면 3 |
| 3:20–4:10 | 데모④ 심사위원 앞에서 사업안 입력 → 30초 영향평가 + 레드팀 리포트 | 화면 4 |
| 4:10–4:35 | 신뢰도: 백테스트 그래프(오차 그대로 공개) | 화면 5 |
| 4:35–5:00 | 사업화(사전협의 SaaS)·확장·ESG, 마무리 | 슬라이드 |

## 2. 데모 안전장치
- 모든 데모 입력은 사전 계산본(`artifacts/demo/`)을 갖고, 실시간 실행이 실패하면 즉시 대체한다.
- 네트워크 없이 동작하는 오프라인 모드(LLM 응답 캐시).
- 데모 노트북 + 화면 녹화 백업 영상.

## 3. 예상 질의응답
| 질문 | 답변 요지 |
|---|---|
| LLM이 규칙을 틀리게 만들면? | 판정은 코드가 한다. LLM 결과는 이중 생성·교차검증·경계 테스트·사람 승인을 거쳐야 쓰인다. 데모에서 불일치 사례도 보여준다. |
| 합성 인구가 현실과 다르면? | 현행 수급 통계로 보정하고, 백테스트 오차를 공개한다. 2단계에서 가명정보 결합으로 정밀화한다. |
| LLM 에이전트 행동 예측을 믿을 수 있나? | LLM은 변화의 방향과 상대 크기만 담당하고, 수준은 실제 통계로 보정한다. Stanford 1,000명 생성형 에이전트 연구가 근거다. |
| 개인정보는? | 실제 개인 데이터를 쓰지 않는다. 공개 집계로 만든 합성 가구만 쓴다. |
| 기존 복지멤버십·모의계산과 뭐가 다른가? | 그것들은 국민 개인에게 안내하는 집행 단계 도구다. 복지트윈은 제도를 설계하는 단계에서 제도 간 상호작용을 검증한다. |
| 실제 도입 경로는? | 사회보장제도 신설·변경 사전협의에 영향평가 리포트를 첨부하는 방식으로 시작한다(기초지자체가 협의의 약 77%). 사보원 시스템에는 판정 규칙 모듈로 공급한다. |
| 부양의무자 같은 복잡한 기준은? | MVP는 근사이고 한계를 명시했다. 가족관계 데이터 결합은 2단계 과제다. |
| 혼자서 가능한가? | MVP는 지금 동작하는 상태로 시연했다. 2단계부터 사회복지 전문가 검수 인력과 협업한다. |

## 2. 원천 저장 규칙
- `data/raw/central/{servId}.json`, `data/raw/local/{servId}.json` — 응답 원문 그대로(가공 금지)
- `data/raw/_manifest.csv` — servId, 수집일시, 소스, 해시
- 가공본은 `data/processed/services.parquet` (아래 스키마)

### 3.2 Household (평가 단위)
```python
class Person(BaseModel):
    age: int
    sex: Literal["M","F"]
    disability: Literal["none","mild","severe"] = "none"
    is_student: bool = False
    employed: bool = False
    earned_income: int = 0        # 월 근로소득(원)
    business_income: int = 0
    other_income: int = 0         # 공적이전 제외

class Household(BaseModel):
    hh_id: str
    region_sido: str
    region_sigungu: str | None
    members: list[Person]
    housing: Literal["own","jeonse","monthly_rent","other"]
    rent_monthly: int = 0
    assets_general: int = 0       # 일반재산(원)
    assets_financial: int = 0
    debts: int = 0
    car_value: int = 0
    # 파생: size, has_elderly, has_child, ...
```
부양의무자 관련 필드는 MVP에서 `support_obligor_income_band`(범주형 근사)만 둔다.

### 3.3 Decision (판정 결과)
```python
class Decision(BaseModel):
    program_id: str
    eligible: bool
    benefit_monthly: int
    trace: list[TraceItem]   # 조건식, 평가값, 통과여부, 출처(source_ref)
```

## 4. 합성 인구 데이터 (요약, 상세는 문서 06)
- 출력: `data/processed/households.parquet` (10만 가구), `persons.parquet`
- 메타: 시드, 사용한 집계표 목록·기준연도
- 개인 식별 가능성 없음(집계표만 사용). 마이크로데이터 사용 시 차등프라이버시 적용 후 생성.

## 5. 품질 점검
- 원천 수집: 목록 건수 = 상세 건수, 빈 선정기준 비율 리포트
- params: 모든 값에 `source`, `verified` 필드 존재 여부 테스트
- 합성 인구: 주변분포(가구원수·연령·지역)가 집계표와 ±2%p 이내

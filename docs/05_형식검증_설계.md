# 05. 형식검증 설계 (L2)

## 1. 목표
"이런 가구가 존재하는가?"를 **샘플링이 아니라 수학적으로** 답한다. 존재하면 Z3가 구체적인 가구(반례)를 돌려준다.
발표 메시지: *사각지대를 사람이 쓰러진 뒤가 아니라 법전 안에서 먼저 찾는다.*

## 2. 변수 모델링
| 가구 속성 | Z3 타입 | 범위 제약 |
|---|---|---|
| size | Int | 1..6 |
| n_elderly, n_child, n_disabled | Int | 0..size |
| earned_income, other_income | Int(천원 단위) | 0..20,000 |
| assets_general, assets_financial, car_value | Int(천원) | 0..2,000,000 |
| housing | Int(enum) | 0..3 |
| region_type | Int(enum) | 대도시/중소도시/농어촌 |

- 금액은 **천원 단위 정수**로 스케일링해 선형 정수 산술(LIA)로 유지한다.
- `median_income(size)`는 size별 `If` 체인(유한 도메인)으로 인코딩한다.
- 비율 곱은 정수 유리수로 변환한다(예: ×0.32 → ×32/100, 양변에 100을 곱해 정수화).

## 3. 인코딩 (`verify/encoder.py`)
- DSL AST(문서 04 §2.3) → Z3 식. 각 제도마다 `elig_P: Bool`, `benefit_P: Int`를 정의한다.
- `income_recognized`는 같은 AST로 정의된 보조 함수로 인코딩한다(평가기와 동일 정의 공유 → 불일치 방지).
- 테스트: 무작위 가구 1,000개에 대해 `engine.evaluate` 결과와 Z3 모델 평가 결과가 일치하는지 확인한다(교차 일관성 테스트).

## 4. 질의 (`verify/queries.py`)

### Q1. 사각지대
> 빈곤선 이하인데 어떤 소득보장 제도에서도 탈락하는 가구가 있는가?
```
assert income_recognized <= median_income(size) * 40/100        # 빈곤 정의(파라미터화)
assert And([Not(elig_P) for P in 소득보장_제도])
```
- `sat` → 반례 가구 + 제도별로 어떤 조건에서 탈락했는지(unsat core 또는 trace 재평가)를 출력한다.
- 반례를 하나 찾은 뒤 차단 절(blocking clause)을 추가해 **서로 다른 유형** 최대 N개를 열거한다(가구원수·연령 구성·주거 형태 기준으로 다양화).

### Q2. 급여 절벽
> 소득이 Δ만큼 늘었는데 가처분소득(소득 + 총급여)이 줄어드는 지점이 있는가?
```
hh1, hh2 동일하되 hh2.earned_income = hh1.earned_income + Δ (Δ = 10천원)
assert disposable(hh2) < disposable(hh1) - threshold
```
- `Optimize`로 손실 폭(`disposable(hh1) - disposable(hh2)`)을 **최대화**해 가장 큰 절벽부터 보고한다.
- 결과는 문서 08의 "절벽 그래프" 화면에 소득 축을 따라 표시한다(엔진으로 소득을 스윕해 그래프를 그림).

### Q3. 중복·모순
> 두 제도가 서로를 배제하는데 둘 다 받을 수 있는 가구 / 어떤 규칙 조합이 공집합인 경우
- 중복: `elig_A ∧ elig_B ∧ (A,B ∈ exclusions)`
- 사문화된 규칙: `elig_P`가 항상 거짓(unsat) → 조건이 서로 모순됨

### Q4. 변경안 영향 (레드팀·시나리오와 공유)
> 현행 규칙 세트 R0와 변경안 R1 사이에 판정이 달라지는 가구 유형
```
assert elig_R0(P) != elig_R1(P)   # 새로 포함/새로 탈락 각각 열거
```

## 5. 설명 생성 (`verify/explain.py`)
반례를 사람이 읽는 문장으로 바꾼다.
```
[사각지대 유형 #3] 2인 가구(70대 1명 + 40대 무직 자녀), 월세, 근로소득 0원,
일반재산 ○○천원 → 소득인정액 ○○원 (중위 ○○%)
 - 생계급여: 재산 환산액 때문에 선정선 초과 (조항: 사업안내 p.○)
 - 기초연금: 소득인정액은 충족하지만 …
```
LLM은 문장을 다듬는 데만 쓰고, 수치는 항상 엔진이 다시 계산한 값을 쓴다.
